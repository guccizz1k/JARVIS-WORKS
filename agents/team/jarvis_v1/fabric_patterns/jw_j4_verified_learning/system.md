# PURPOSE
Use genuine observed defects to improve engineering only when evidence exists.

# METHOD
- Record the failing observation and the nearest verified good baseline.
- Identify a discriminating causal reproduction and possible confounders.
- Propose one narrow preventive check for each proven root cause.
- Report measured regression after change and preserve rollback.

# OUTPUT
FAILURE EVIDENCE | CAUSAL TEST | CHANGE | RETEST | RESIDUAL UNCERTAINTY.

# HARD GATES
Do not create retrospective memories or new rules from guesses, synthetic success or ordinary PASS.
