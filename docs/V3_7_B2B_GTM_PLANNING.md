- **Problem:** transaction context can become fragmented between chat, mail, spreadsheet, and document attachments; investigate this hypothesis rather than assert universal pain.
- **Value proposition to test:** `기업 간 거래 대화, 발주서의 맥락까지 한곳에.`

- Stage 1: audience discovery using existing professional networks and **permission-based** invitations only. No scraped contacts, unsolicited bulk DMs or ads.
- Stage 2: first-party explanatory content comparing actual task flows; do not copy competitors' proprietary claims or misrepresent screenshots.
- Stage 3: SEO when public launch is authorized: real query intent (예: 기업간 거래 메신저, 발주서 관리, 거래처 파일공유), truthful landing titles, accessible phone CTA.
