# V6.9 — 복합 거래 내부 미수금 조정 검토

- 기존 invoice 원본 품목·원본 공급가액·원본 부가세·입금 기록은 보존.
- 반품은 청구 품목 ID에 대해 수량 단위로 검토하며 누적 수량 초과를 차단.
- 할인은 공급가액 감소, 운임은 공급가액 증가로 모델링. 단일 taxable/exempt 세율만 가정.
- 단일 공급가액 기준 KRW 10% 반올림; **특수 세무 거래, 혼합 과세, 별도 환불, 재고 변경, 공식 수정세금계산서 발행은 미지원**.
- 요청은 멱등키로 검증·저장, 관리자만 승인/반려, 결정은 별도 immutable 테이블로 기록.
- 승인 뒤 조정 합계가 기존 입금액보다 적어지는 경우 차단(환불 미구현).
- 승인된 조정 합계만 내부 미수금 API·대시보드·추가 입금 상한에 반영.
- 테넌트 격리/감사 로그/원본 보존, 최대 20건 대기·200건 이력 한도.
- SQLite 로컬 검토용, 실제 PG/RLS/고객 세무 검증 및 운영 배포는 별도.
