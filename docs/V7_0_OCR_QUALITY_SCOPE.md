# V7.0 문서 인식 정확성 강화 (검토 후보 전용)

## 적용
- 동일 항목에 서로 다른 값이 발견되면 마지막 입력으로 덮어쓰지 않고 해당 추출값을 빈칸 처리; 원본 대조 필요
- 한국 사업자등록번호 10자리 체크섬 검사 (등록/휴폐업 여부 조회는 **아님**)
- 날짜 실존성·숫자 오인식·공급가액+부가세=총액 검증 및 오류 분류
- 기존 증빙 검토 화면에 인식 검증 상태만 최소 추가; 수동 원본 확인 의무 보존
- OCR 발췌 일부에서 주민등록번호·전화번호·이메일·사업자번호의 **제한적** 비식별화. 완전한 DLP/PII 검출 보증 아님
- 유효한 값만 자동 기록되는 구조 **아님**. 사람 승인 없이 원장/결제/재고를 변경하지 않음

## 정확도 평가 원칙
- `scripts/benchmark_evidence_v70.py`: 생성된 허구 사업자/거래정보로 XLSX 40개·PNG 3개 골든셋 대조
- 문서 전체 필드 엄격 일치와 오류가 난 값의 보류율을 함께 측정. 정밀도 100% 등의 표기는 평가 경계를 가리지 않도록 분모를 함께 제공
- 합성 데이터로 측정한 수치는 고객사 실문서 OCR 성능이 아님. 실문서는 개인정보 처리계약·동의·비식별 후에 검증할 것
- 퍼센트 신뢰도 제공 안 함(보정/calibration 검증 자료 없음)
