# J TEAM V13.2 — YouTube / Instagram 기본 콘텐츠 포맷 프로토콜

## 적용 범위
사용자가 별도 예외를 지정하지 않는 한 유튜브 Shorts/영상/설명·인스타 Reels/피드/캡션의 조사, 기획, 대본, 본문, 첫 콘텐츠 기획에 **기본적으로** 적용한다. 개발 업무, B2B 문서 등 비소셜 요청에는 적용하지 않는다. 이 규칙은 기존 V13.0 5역할과 J1~J6를 보존하며, 공개 게시/모델 실행 권한을 추가하지 않는다.

## 출발점: 검증된 형식 + 시장과 자체 소재
1. **원본 포맷 조사:** 다른 카테고리에서 실제 성과가 관측된 POV, 티어리스트 또는 추가로 조사된 포맷 후보를 찾는다. 게시물 URL, 원본 시장, 영상 게시일, 조회수/좋아요 등 지표가 관찰된 날짜, 플랫폼을 기록한다. 첨부 예시의 *269만·377만·100만*은 출처를 독립 검증하기 전까지 **UNVERIFIED**이며 콘텐츠/마케팅 문구에서 성과 보증으로 사용하지 않는다.
2. **목표 시장 검색:** 목표 시장·언어·타깃 고객을 정하고 적어도 서로 다른 검색 3건을 수행, 경쟁 사례/조회 근거를 기록한다. 검색에서 안 나와도 **빈자리 확정**이 아니다. 알고리즘 성과와 시장 적합성은 서로 다르다.
3. **3가지 의미 있는 변형:** (a) 타깃과 해결할 문제 (b) 본인 자료, 사례·인사이트, 콘텐츠 본문 (c) 대본·연출·비주얼·음성. 형식만 참고하고 영상·음악·스크립트·캐릭터 자산을 무단 복제하거나 교체 가능한 기계적 반복물을 만들지 않는다.
4. **3개 오리지널 파일럿 콘텐츠:** 포맷 가설을 유지하면서 주제·가치·소재가 다른 3편을 기획한다. 썸네일/첫 2초 훅/본문/결론/CTA/캡션/권리·고지/업로드 정보를 제작하고 권한이 있을 때만 게시한다. 게시 결과 전에는 예측 수치를 실측으로 표현하지 않는다.
5. **7개 콘텐츠 시작안:** 매번 유용한 소재가 다른 7개 콘텐츠 순서를 기획한다. 3개 파일럿과 나머지 4개의 후속안은 소재 차별화가 필수다.
6. **사후 평가:** 게시 ID·URL, 실제 노출/조회·평균 시청 시간·완주·저장·공유·팔로우·클릭을 가능한 경우 기록한다. 동일 기간·플랫폼·비교 기준, 실제 출처를 명시한다. 공식 데이터가 없으면 NOT MEASURED. 개선·확장은 3개 파일럿 실측 검토 후 결정한다.

## 역할 분담
- 대리: **원본 포맷·시장 조사** 및 URL/관측일/사용권 검증. 대안 가설 제시.
- 차장: **타깃·차별화·콘텐츠 전략**, 3가지 변형 및 첫 7편 설계.
- 과장: **오리지널 대본·자막·썸네일 콘셉트·캡션/해시태그**, 파일럿 3편 제작.
- 부장: **독립 검수**, 원본 무단복제·성과 뻥튀기·저작권·정책·근거/완주 지표 확인.
- 총괄 자비스: **최종 편집·승인 범위 관리**, 연결된 계정 게시 전 승인 및 실제 게시/성과 기록.

## 기본 카드 (포맷 선택 후 매 영상별 필수)
- 시장/타깃, 후보 포맷(POV/티어리스트), 출처 링크·관측일·검증 상태, 시장 경쟁도 **가설**
- 원본 소재·권리, 3가지 변형, 독립적 가치/근거
- 0~2초 훅 / 누구의 문제인지 / 나만의 시연·정보 / 결론 또는 보상
- 플랫폼별 제목·썸네일·캡션/설명·CTA, 자막·원본/합성 표시
- 배포: **NOT_PERFORMED** until approved connector sends; 3편 실측/7편 계획
- 실패·학습: 결과를 확인한 뒤 채택/폐기/다시 실험. 성과 보장 또는 바이럴 확정 불가.

## 법적·플랫폼 품질
YouTube는 반복·대량 생산·재사용의 낮은 변형 콘텐츠 수익화를 제한한다. 자료:
- https://support.google.com/youtube/answer/1311392
- https://support.google.com/youtube/answer/2490020

인스타그램/유튜브의 사용규정, 음악·이미지·영상 사용권, 광고·협찬 표기, 합성 매체 고지, 개인정보를 게시 전 검토한다. 플랫폼의 최신 규정과 유저가 승인한 계정별 권한이 우선한다. POV/티어리스트 방식 자체만으로 성과가 보장되지는 않는다.
