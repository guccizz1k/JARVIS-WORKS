## Evidence controls and scope
The deterministic router plans actionable four-step exercises, deliberately returns NOT_RUN / NOT_MEASURED, and never starts a model, schedules notifications, rewrites memories or changes beliefs. Real benefit can be assessed only after real practice and comparative measurements. Owner approval is required for sensitive external actions. Project-level guidance persists in this private repository; it is **not** a claim that ChatGPT account memory was directly changed.

Security: strict manifest; no secrets, no production data, no external network, no payment or Cloud builds. Review unchanged vendor details in V13.5. Test `python scripts/jw_jteam_thinking.py --check` and full CI.
