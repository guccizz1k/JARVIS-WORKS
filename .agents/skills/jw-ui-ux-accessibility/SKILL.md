# JARVIS-WORKS UI/UX quality
J1–J6 review skill, release BLOCKED until exact-SHA PASS evidence.
1. Inspect real app/static/index.html, style.css, and app.js; never assume React. Map navigation, dense tables, messenger, file upload, preview and confirmation.
2. Compare two UX approaches (minimal and polished) with user tasks, component consistency, readable Korean text, error/empty/loading states and a rollback plan.

5. Identify a reproducible problem before changing layout, run browser regressions and report PASS/FAIL/NOT RUN. No main merge or paid deployment.
